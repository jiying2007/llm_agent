# vibeflow 治理覆盖说明

## 定位

`vibeflow` 是 SDD + Harness 交付编排层参考源，用于观察阶段门禁、任务流转、审查、测试、发布和复盘机制。

## 使用边界

- 默认只读分析，不直接安装插件或改写运行目录。
- 可借鉴内容应先进入 `llm_agent` 采纳矩阵，再由 `agent-dev-kit` 压实为可验证资产。
- 不把 VibeFlow 的 Claude Code 插件安装流程直接作为 Codex 生产链路。

## 修改约束

- 优先保持上游原貌；除根仓托管治理覆盖文件外，不改动上游内容。
- 采纳时必须明确哪些能力适合 Codex，哪些因平台绑定或运维成本不迁移。
- 文档文件保持 `100644`，只有实际可执行脚本保留 executable bit。
