# 探索记录目录说明

## 目录结构

```
docs/explorations/
├── README.md                    # 本说明文件
├── <exploration-id>/            # 探索记录目录
│   ├── exploration.md          # 探索记录文档
│   ├── findings.md             # 发现文档
│   ├── conclusions.md          # 结论文档
│   └── references/             # 参考资料目录
└── index.md                    # 探索记录索引
```

## 目录用途

### 1. 探索记录
- 记录探索性工作
- 保存探索过程
- 支持探索复用

### 2. 知识积累
- 积累探索经验
- 记录发现和结论
- 支持知识传承

### 3. 决策支持
- 为决策提供依据
- 支持方案评估
- 提供参考信息

## 使用规范

### 1. 探索目录命名
- 使用kebab-case格式
- 包含探索ID
- 例如：`modbus-tcp-feasibility`

### 2. 文件命名规范
- 使用小写字母和连字符
- 包含文件类型后缀
- 例如：`exploration.md`、`findings.md`

### 3. 时间管理
- 记录探索时间
- 维护探索历史
- 支持时间查询

## 探索流程

### 1. 启动探索
```bash
mkdir -p docs/explorations/<exploration-id>
```

### 2. 执行探索
- 定义探索目标
- 设计探索方案
- 执行探索活动
- 记录探索过程

### 3. 分析发现
- 整理探索数据
- 分析探索结果
- 提炼关键发现
- 形成探索结论

### 4. 记录总结
- 编写探索记录
- 整理发现文档
- 形成结论文档
- 更新探索索引
