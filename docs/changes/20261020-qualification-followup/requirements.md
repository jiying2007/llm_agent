## 证据与权限边界

- GitHub 连接器/API 用于只读源码、issue、workflow 与证据核验，以及用户授权的受保护 PR、合并和已有 issue 更新。禁止直接主线写入、规则绕过、凭证读取与输出。
- 复核器本身仅在显式输出位置写报告，不提交代码、不更新 issue、不执行提供方请求、不安装或激活 runtime。输出只有诊断和下一步建议，没有审批权限。
- 真实注册人类 Owner 的语义判断、认证 runtime、实际 A/B 效果以及真实 field 观察不能由代码检查替代。日期届满不等于完成观察；缺少记录不等于零事故。
- 本环境的真实 Knowledge Provider 入口 `/root/codex/scripts/knowledge-provider.sh` 不存在，实际调用退出 127；不将本地 fixture 或固定源码子模块冒充该运行环境。耐久事实保存在本次 Git 变更与原有 issue，不静默写入记忆。
- 本轮零新增付费资源。已有付费授权参数或未知成本的模型工作流不因诊断而启动。

## 风险与回滚

聚合器可能误读既有命令的退出码或把历史/局部通过合成为资格；因此逐项校验 schema、保留原始退出码并固定报告无资格授权。定时任务可能延迟或被停用，必须同时保留 push 和人工触发入口及采集时间，不宣称持续运行保证。

回滚为回退本变更新增的聚合入口和 workflow；既有证据、审批记录、信任注册和六项 certifier 保持各自权威。
