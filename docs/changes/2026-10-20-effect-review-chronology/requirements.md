# G22 Owner 评审时间顺序：需求

## 目标与边界

Owner reviewed_at 必须不早于其依赖证据的已验证完成时间，并继续拒绝未来日期。内容摘要对应关系与审核时间因果关系都必须成立。

不生成或修改真实 Owner 记录，不替代人类语义判断，不改变预注册、签名验证、活动来源与资格授权边界。

## 验收

1. 现有合法活动、完成时间与评审时间同秒的边界继续通过。
2. 2000 年、收据签名前、聚合完成前的评审均拒绝。
3. 负例只改变 reviewed_at 及对应外层索引摘要；签名与原始测量材料保持不变。
4. 晚到的签名时间和 measurement as_of/through 各自受到独立验证。
