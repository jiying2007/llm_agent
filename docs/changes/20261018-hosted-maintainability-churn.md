# Hosted maintainability churn candidate collection

## Change contract
Route an optional read-only Git history churn candidate through the existing `tools.codex_assets.maintainability_evidence` and existing unit regression. Do not add a new asset/metric SSOT, spend provider budget or mutate Root's backlog.

## Safety
- Protected main exact source with full history; checkout token is read-only and not persisted.
- Explicit review-required candidate only; no auto-approval, threshold or scorecard mutation.
- Empty/no-distinct-revision windows produce `not-available`; invalid source, output budget or secret-like path fails closed.
- Temporary artifacts retained 14 days only; promote through existing reviewed evidence contract if applicable.

## Acceptance
Workflow syntax and pinned Actions compatibility; the existing generator's deterministic and negative tests; the new static workflow policy assertion; actual hosted PR job; protected merge and fresh-main. No other maintainability axis is inferred as measured.

## Rollback
Retire the schedule/dispatch entry through a reviewed PR while retaining the CLI and historical reviewed evidence. Do not silently overwrite long-term assets.
