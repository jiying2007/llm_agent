# 目标与验收

本轮承接 Owner 已授权的自动推进和独立自动审核，晋升正式 ADK 8.0.37，并将 Root 的审核说明同步到现有消费者行为。

1. ADK 必须先完成受保护 PR、精确主线 CI 和不可变 Release；Root 通过现有 canonical promotion 固定正式 commit、tree、manifest 与原始签名凭证。
2. G22 说明使用 v6、逐资产决定和 source-pinned ADK 的实际 owner-delegated independent AI review。
3. LTA 说明准确表达 summary review 的 registered-human / owner-delegated-ai 两种现有模式；现场 actor 仍须是注册 human operator，完整账本、30 天窗口、末 24 小时真实观测、晚记录顺序与 Git 绑定继续生效。
4. LTA 风险说明与实现一致：未解决的 blocking 风险或 review hold 阻止终局资格；accepted / mitigated 规则保持原有语义。
5. 整个晋升按 L4 生成最终快照验证计划，执行实际门禁，保留失败与环境限制；由独立代理审核最终 diff，再核对受保护 PR 和 fresh-main 结果。
6. Native、G22、LTA 和条件 Product M5 的真实证据由现有消费者判定。组件发布、AI 审核和诊断采集本身不生成运行或现场事实。

回退通过受保护变更恢复或修复精确组件 pin 与受影响说明；保持签名、源绑定和 fail-closed 验证约束。
