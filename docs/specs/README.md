# 规格说明目录说明

## 目录结构

```
docs/specs/
├── README.md                    # 本说明文件
├── <spec-id>/                   # 规格说明目录
│   ├── spec.md                 # 规格说明文档
│   ├── design.md               # 设计文档
│   ├── api.md                  # API文档
│   └── examples/               # 示例目录
└── index.md                    # 规格说明索引
```

## 目录用途

### 1. 规格管理
- 管理项目规格说明
- 维护规格版本
- 支持规格查询

### 2. 设计驱动
- 驱动开发流程
- 指导代码实现
- 确保实现一致性

### 3. 知识积累
- 积累设计经验
- 记录最佳实践
- 支持知识传承

## 使用规范

### 1. 规格目录命名
- 使用kebab-case格式
- 包含规格ID
- 例如：`modbus-tcp-protocol`

### 2. 文件命名规范
- 使用小写字母和连字符
- 包含文件类型后缀
- 例如：`spec.md`、`design.md`

### 3. 版本管理
- 使用语义化版本号
- 记录版本变更历史
- 支持版本回溯
